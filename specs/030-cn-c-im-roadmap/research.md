# Research: 030 国内经营触达 IM 版图（2B / 2C / 电商）

**Date**: 2026-09-11  
**Status**: 调研纪要（支撑 [plan](./plan.md)；**非实现授权**）  
**对照**: [026](../026-im-channel-roadmap/research.md)、[029](../029-qq-im-channel/research.md)、[031](../031-douyin-im-channel/research.md)

## 1. 问题怎么拆

用户需求是「大概方向」：成熟开放平台、企业刚需（含电商外卖）、2B/2C 都要覆盖。  
调研任务不是立刻选一个写代码，而是回答：

1. 市场上有哪些**可官方对接的消息面**？  
2. 每个面是 **会话式 IM** 还是 **业务事件推送**？  
3. OryxOS 已有什么、缺什么？  
4. 谁先做深度 research、谁 Later/Won’t？

### 1.1 直连 vs 第三方插件（产品争议）

| 立场 | 论点 | 本 research 取舍 |
|------|------|------------------|
| 同事：插件/云客服已支持就接入 | 快、少申权限、一套接多家 | 可作**可选过渡**，缩短空窗 |
| 你：Agent OS 应直连 | 延迟/配额/故障边界可控；渠道是 OS 能力不是二郎腿 | **默认与完成定义 = 官方直连** |

**决定**：主路径直连；聚合不替代、不挡排期。飞书/企微/钉钉/QQ/抖音已按此落地，后续经营触达同纪律。

**经验依据（为何不赌中台）**：为求快接第三方中台后，节奏与正确性绑在对方人力与更新上——能力不够、文档滞后、错误百出时，业务侧只能干等或自己擦屁股。Agent OS 若再走这条路，等于把「渠道一等能力」外包出去；短期省对接，长期付控制权。

### 经营触达要单独建「国内表」的原因

员工 IM ≠ 店铺客服 ≠ 公众号/小程序客服 ≠ 外卖订单推送。  
混在 026 海外波次里会排错优先级；故由 **030** 管国内经营触达。

## 3. 微信生态（国内 C 对客，缺口最大之一）

| 产品 | 双向？ | 会话窗 | 备注 |
|------|--------|--------|------|
| **微信客服**（企微开放的对微信用户客服） | 是，官方 API | 平台规则 | 与现有 `wecom` **应用内机器人**不同；用户在微信侧 |
| 服务号客服消息 | 是 | 约 48h | `message/custom/send`；须认证服务号 |
| 小程序客服 | 是 | 约 48h | 推送 URL + 发送接口；也可只用官方工作台 |
| 微信小店自研客服 | 是 | 约 48h / 约 5 条 | 商家自研；**第三方 ISV 往往不能代接** |

**调研结论**：若「国内 C 端经营触达」要补洞，**微信客服（W1）应进 P1 research**，不能认为「已有企微渠道 = 已覆盖微信用户客服」。

| 平台 | 结论 |

## 5. 电商客服

| 平台 | 结论 |
|------|------|
| 淘宝/天猫 | 开放平台 + 商家授权 + TMC 成熟；**但**「店铺买家会话」须钉死具体消息主题与发信 API。存在仅亮灯、仅交易消息、内部调试接口等陷阱。天猫与淘宝同 TOP → 单模块 |
| 京东 | 咚咚相关能力走宙斯权限，公开材料散 → 🔍 |
| 拼多多 | 业界大量「开放平台回调 + 主动发信」叙述；**必须以官方文档接口名为准**；Cookie 模拟 ❌ Won’t |
| 抖音电商 | 可能与抖音 IM / 小程序消息推送客服重叠 → 合流评估，避免双模块 |

## 6. 外卖 / 本地生活

美团、饿了么开放平台对**订单、催单、配送、门店**推送很成熟，这是履约刚需。  
公开材料里少见与「淘宝千牛式买家-商家聊天」同构的通用 IM API。

**结论**：

- 订单/催单 → 适合 **notify 或业务工具**，不进「IM 渠道完成」勾选。  
- 若存在独立「商家客服会话」产品，再单独立项 research；当前标 🔍，**不排渠道 BUILD**。

## 7. 禁止清单（调研纪律）

| 禁止 | 原因 |
|------|------|
| 个人微信 / QQ 协议号 | 不合规 |
| 聚合云客服作为唯一入站 | OS 要直连可控 |
| 交易投诉当客服 IM | 支付宝 complain 等 |
| 订单 webhook 当客服 IM | 美团/饿了么典型 |
| 未钉死 API 就开 `oryxos-channel-*` | 违反先 PLAN 再 BUILD |
