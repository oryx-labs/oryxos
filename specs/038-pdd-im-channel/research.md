# Research: 038 拼多多商家客服（E3）

**Date**: 2026-09-12  
**Status**: IN PROGRESS — **尚不可 BUILD**（官方 API 名须登录开放平台控制台钉死）  
**对照**: [plan](./plan.md)、[030](../030-cn-c-im-roadmap/plan.md)

## 目标

官方直连：**买家 ↔ 店铺客服会话**文本由 Agent 收发。  
模块拟 `type: pdd`（或 `pinduoduo`）。

## 已排除的「假完成」路径

| 能力 | 为何不算 |
|------|----------|
| Playwright / 浏览器自动化客服工作台 | ❌ Won’t（Cookie/协议类，违规风险） |
| 仅订单/物流/售后 **业务事件**推送 | 不是聊天会话 |
| 社区博客里未经核对的 `pdd.ddk.message.send` 等 | DDK 偏推广；**不得**未经官方文档确认当客服发信 |
| 第三方聚合云客服作为唯一入站 | 可过渡，不可当 OS 完成定义 |

## 候选真路径（待控制台核对）

公开可确认：

| 项 | 现状 |
|----|------|
| 开放平台 | https://open.pinduoduo.com — 文档中心大量内容需**登录**后可见 |
| 角色 | 「商家服务商 / 电商软件服务商」类应用 + 商家授权；或大型商家自研 |
| 网关候选 | 社区常见 `https://gw-api.pinduoduo.com/api/router`（须官方文档确认） |
| 签名 | 社区描述 MD5/HMAC 参数排序签名；**以官方「签名算法」页为准** |
| 入站 | 开放平台配置**消息推送 / 回调 URL**；要求快速 ACK（社区称约 5s），再异步调发信 API |
| 出站候选名（**未官方钉死**） | 社区/示例仓库常写 `pdd.customer.service.message.send`、session/history 相关；**必须在控制台 API 列表用账号核验后才能写入实现 PLAN** |

→ 本 research **不把社区接口名标为已钉死**。  
→ 有开放平台账号后：截屏/抄录「客服/会话」类 API 英文名 + 权限包 + 回调报文样例 → 再升 READY。
